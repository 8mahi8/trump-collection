# トランプコレクション V2｜学校UI品質改善・第1回（2026-10-28）

## 出発点
- 学校のiPad Safariで、友達同士のFirebase接続と対戦には実際に成功。
- 操作時の重さ、大富豪の誤整列、チャット欠落は直前の修正で対策済み。ただし修正版の実機評価は未実施。
- 今回は旧 `index.html` のカード/ゲーム選択デザインと、`v2/ui/table-renderer.mjs`、`board-surfaces.mjs`、`table.css`、`online-shell.css`、`online-app.mjs` を照合し、「4ゲームの見た目と操作フィードバックが薄い」点を改善する。

## 今回実装（Draft PR #2 開発ブランチのみ）
1. **大富豪の選択ガイド**：権威エンジンから渡される `legal.playMoves` を直接使用。未選択時の組み合わせ数、選択中の成立/未成立/不成立を表示。ルールをUI側で再発明しない。
2. **次に選べるカードを強調**：現在の選択が含まれる合法手の残り候補を別色で強調し、複数枚出しの分かりにくさを軽減。
3. **選択解除ボタン**：誤った組み合わせを一括解除。ボタンの状態、テキスト、CSS classのみを更新し、以前直した「選択する度に全画面再描画」は復活させない。
4. **手札の視認性**：並び順ボタンを「並び：強さ順/マーク順」にし、選択枚数を「○枚を出す」へ反映。幅の狭い端末でも邪魔になりすぎないサイズに調整。
5. **大富豪の場情報**：場に出ている枚数、最後に出した席（CPU/自分の区別）、革命、直近イベントを読みやすいチップへ整理。元の公開viewにない情報は生成しない。
6. **神経衰弱**：背の低い横画面（max-height:430px）では 6列×4行から 8列×3行へ変更。場と手札の重なりを抑える。
7. **共通ロビー**：旧版のゲームタイル表現を参考に、4ゲームのアイコン、面構成、選択色を調整。共通5桁ルーム・CPU席・チャットは変更しない。
